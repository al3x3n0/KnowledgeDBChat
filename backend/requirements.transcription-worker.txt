# The audio stack, installed on top of the API image rather than beside it.
#
# These are the only packages transcription needs that nothing else in this
# codebase does. They came out of requirements.txt because every API, Celery and
# beat container was carrying them -- with numba and llvmlite pulled in
# underneath -- to run a feature only this worker performs.
#
# Installed by Dockerfile.transcription-worker, which builds FROM the API image
# for its application code, clients and ffmpeg -- not for torch. Torch left the
# API image when embeddings moved to ONNX Runtime, so it is installed here, and
# this is now the only image in the stack that has one.
#
# torchaudio is NOT here. It must come from the CPU wheel index, the same way
# torch does in the API image, or pip resolves it against PyPI and pulls the
# CUDA build of torch in behind it -- roughly 2 GB this stack cannot use. The
# Dockerfile installs it in its own step for that reason.

# torch and transformers live here now, not in the API image: Whisper and the
# Russian ASR pipeline are what is left of their consumers. The Dockerfile
# installs torch from the CPU wheel index in its own step for the same reason
# torchaudio needs one -- resolved against PyPI it is the ~2 GB CUDA build.
transformers==4.35.2
openai-whisper>=20230918
librosa>=0.10.0
ffmpeg-python>=0.2.0

# for each before using it.
